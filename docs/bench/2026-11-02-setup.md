# Стенд настройки — 2026-11-02

Оборудование: ESP32-S3 N8R2 (8 MB flash / 2 MB PSRAM) и ESP32-C3 Super Mini (4 MB flash). На обеих платах только USB, без датчиков, реле и насосов. Проверки выполнялись на macOS; Windows/Linux запускатели подготовлены, но на этих ОС физический стенд не проверялся.

## Программные проверки

- `npm run check`: публичный контракт, Setup Schema и примеры, документация и JavaScript — пройдено.
- Native C: domain/protocol, API/sensors, AEAD/replay и новый setup parser под sanitizers — 4/4.
- Python: проверка пакета, профиля, MD5 разметки, app-only update на модели flash и отказ непустого NVS — 4/4. Генерация provisioning, сертификата, индивидуальных ключей и Hub без C3 — 5/5.
- Chromium: реальные HTML/JS под CSP, импорт access-файла без отправки лишних полей, вход/выход, Wi-Fi без повторной отправки при потере ответа, импорт pairing, мобильная ширина без горизонтальной прокрутки — пройдено с mock API.
- ESP-IDF v5.3.4: сборки S3 N8R2, S3 N16R8 и C3 — пройдены. N16R8 на физическом стенде отсутствовала.

## Физический стенд

1. Определены чипы и flash. Перед обновлением сохранены только app-разделы; NVS не копировался для отката.
2. Новый USB-мастер обновил app-разделы S3 и C3; esptool подтвердил hash записи. Загрузчик/таблица/NVS не записывались.
3. Прежний сертификат сверился с отпечатком USB-комплекта; вход с прежним admin key успешен. Домашняя сеть и существующая связь C3 сохранились, C3 вернулся online.
4. `/setup` и `/setup.js` возвращают 200; неавторизованный Setup API — 401; чужой Origin — 403; неправильные параметры Wi-Fi и pairing — 400.
5. Повторный импорт существующего C3 с другими ключами — 409, действующая связь не заменена.
6. Проба несуществующей сети: после ограниченного ожидания восстановлена прежняя домашняя сеть.
7. Успешная проба текущей сети: состояние `connected`, credentials сохранены. C3 восстановил связь после переключений.
8. На реальном стенде HTTP-ответ мог теряться при смене сети. Страница теперь проверяет состояние, не повторяя POST; этот вариант отдельно проверен Chromium-тестом.

Команды полива не отправлялись. Отключение питания посреди NVS commit, долговременная работа, первая привязка нового пустого C3 и первый запуск пустого Hub требуют отдельных аппаратных испытаний. Текущие рабочие устройства не сбрасывались ради этих проверок. Web OTA не реализован.
