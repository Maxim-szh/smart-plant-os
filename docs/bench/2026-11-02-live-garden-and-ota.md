# Реальный сад и обновления: 2026-11-02

Стенд: ESP32-S3 N8R2 и ESP32-C3 Super Mini, только USB, без датчиков, насосов и клапанов. SDK ESP-IDF 5.3.4. N16R8 проверяется сборкой, физической платы этого профиля в испытании нет.

## Программные проверки

- 13 native C-тестов: доменная логика, API, реестр датчиков, миграция метаданных/замена контроллера, безопасная отвязка, стабильные replay epochs, pairing, криптография, маршрутизация веба и валидация OTA-образов. Все прошли; native target использует ASan/UBSan согласно конфигурации CMake.
- 7 Python-тестов USB-мастера и 4 OTA-теста: MD5 таблицы, пределы образа, otadata CRC, выбор противоположного слота, порядок записи при миграции, сохранение NVS и прежнего приложения. Все прошли.
- JSON Schema и документационные проверки `npm run check` прошли.
- Три Chromium-сценария: setup/авторизация/Wi-Fi, реальный сад/отдельное демо/комнаты/имитация ADC-калибровки/offline/адаптивность, OTA-профиль/SHA/порционная отправка/подтверждённый reboot/неопределённый ответ без автоповтора. Все прошли. ADC в этих проверках имитируется API; это не физическая проверка датчика.
- Сборки N8R2, N16R8 и C3 проходят; приложения помещаются в новые OTA-слоты.

## Проверено на платах

Проверен сохранённый TLS-отпечаток перед передачей ключа владельца. Обе платы переведены из factory в ota-v1 через USB. После миграции подтверждены прежний сертификат и ключ, домашняя сеть, идентичность/привязка C3, имя растения и точное совпадение управляющей конфигурации с исходным снимком. NVS не стиралась и не заменялась.

При первом begin OTA обнаружен реальный тайм-аут HTTP: однократное стирание большого раздела превышало односекундный срок ожидания API. Исправлено последовательным стиранием ESP-IDF OTA и посекторной подготовкой staging по мере поступления данных. После исправления полный образ Hub принят через HTTPS и выполнен перезапуск. 3 ноября завершён сквозной сценарий C3: образ 852720 bytes передан через зашифрованный ESP-NOW, контроллер перезагрузился и подтвердил VALID нового слота с новой boot epoch. Hub сообщил completed. В первой финальной проверке C3 не отображался online; после диагностического USB-перезапуска связь восстановилась, а доступ, сеть и конфигурация полностью совпали с исходными. Один повтор полного C3 OTA с непрерывным журналом прошёл: VALID нового образа, online без дополнительного перезапуска после OTA, прежние ключи/имя/конфигурация. Ошибки TX callback в повторе не зафиксированы. Причина первого эпизода offline не установлена; он не объявляется исправленным. Перед признанием обновлений стабильными необходим отдельный прогон восстановления телеметрии после OTA.

## Границы

Не проверены физические датчики/калибровка, включение исполнительных устройств, искусственный обрыв питания на каждой границе записи, намеренно неработоспособный образ с rollback, несколько физических C3 и длительная нагрузка. Проверка штатного OTA не доказывает все сценарии восстановления. Signed releases/Secure Boot и защита первого pairing от MITM этой работой не добавлены.

Завершение стендовой серии: 2026-11-03. PR остаётся черновиком до расследования одиночного offline-эпизода. Сброса настроек или потери привязки не наблюдалось.
