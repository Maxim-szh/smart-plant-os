# Локальный HTTP и интерфейс установленного приложения

## Что изменено

Экспериментальный параметр сборки Hub `CONFIG_SP_WEB_LOCAL_HTTP=y` включает
HTTP на порту 80 вместо HTTPS. По умолчанию остаётся HTTPS. Включить параметр
можно через `idf.py menuconfig` → Smart Plant web transport → Use HTTP for
the local Hub interface (только ESP32-S3), затем собрать обычный OTA-пакет.

Это профиль для доверенной локальной сети: HTTP не шифрует ключ владельца,
сеанс и данные. Авторизация и проверка Origin сохраняются. HTTP использует
отдельную HttpOnly/SameSite=Strict cookie, чтобы старая Secure-cookie HTTPS
не мешала входу. Проброс порта в Интернет для этого профиля не предусмотрен.

Ссылки мастера настройки используют текущую схему страницы. Обновление через
браузер работает и без SubtleCrypto: Hub обязательно проверяет SHA-256 всего
образа до выбора загрузочного раздела. SHA-256 проверяет целостность, а не
подлинность издателя пакета.

В установленном PWA скрыта верхняя панель с логотипом. Учтены display-mode
standalone и navigator.standalone на iOS. Обычная вкладка сохраняет панель.
Текст интерфейса не выделяется при нажатиях; поля ввода и диагностические
значения остаются доступными для выделения и копирования.

## Проверки

На S3 N8R2 проверены вход по HTTP, повторная загрузка, отказ без авторизации,
отклонение чужого Origin, сохранность растений и домашнего Wi-Fi после OTA.
Пользователь подтвердил открытие растений в Safari на iPhone без предупреждения
о сертификате. Браузерные сценарии проверяют установленный режим, диалоги,
редактируемые поля и OTA по HTTP/HTTPS. Проверки контрактов и 20 host-тестов
прошли; собраны S3 и C3. Для изменений только веб-интерфейса C3 обновлять не нужно.

После смены схемы нужен новый ярлык с HTTP-страницы: старый ведёт на HTTPS.
Установка ярлыка и его иконка на настоящем iPhone ещё требуют проверки.
HTTP не даёт secure context: Service Worker и другие зависящие от него API
недоступны. Возможности домашнего ярлыка зависят от браузера и ОС.

## Ограничения эксперимента и возврат

Это не смена транспорта по умолчанию: общие инструкции установки пока описывают
HTTPS, а строка адреса в стартовом USB-журнале ещё рассчитана на HTTPS.
Отключение опции и OTA пакетом HTTPS возвращает прежний транспорт, не стирая
NVS, ключи и растения; после него нужно открыть HTTPS-адрес заново.
