# Доверенные браузеры и уход — 2026-11-03

Версия 0.4.0-abi1, safety data ABI 1. Физический Hub — ESP32-S3 N8R2. C3 отключена владельцем, не прошивалась и не участвовала в тестах. Исполнительные устройства и датчики не использовались. Скриншоты не делались; в прежнем setup-тесте добавлен SP_NO_SCREENSHOTS.

## Проверено

- Host-комплект 18 наборов и целевые сценарии новых служб: независимые доверенные/временные сеансы, digest-only store, истечение временного допуска, reload, отзыв и ошибка commit, смена owner key и повреждение списка допусков; дневник с идемпотентным UUID, сохранение/загрузка, выполнение напоминания, revision conflict и неудачный commit; история с ограниченным минутным наблюдением, checkpoint, повторной загрузкой, missing/fault и day/week.
- Публичные схемы, примеры, unknown-field rejection, требования к напоминанию, синтаксис JS, generated profiles и ссылки. Реальные ответы S3 DiaryPage/Measurements проверены по публичной схеме.
- Один целевой браузерный сценарий: два независимых браузера, HttpOnly cookie и reload без ключа, отзыв другого доступа, неудачный logout, русские подписи/границы элементов выбора, offline-контроллер, создание/выполнение напоминания и разрывы на графике/выбор недели. Отдельно проверен существующий мастер входа/Wi-Fi; автоматические повторы изменяющих запросов не добавлены.
- SDK-сборки Hub N8R2, Hub N16R8 и Node C3. Для реальной записи использован только N8R2.
- На S3: USB-обновление неактивного слота без стирания NVS, запуск 0.4, домашний Wi-Fi и точное совпадение старого каталога/привязок. Восемь файлов интерфейса по HTTPS совпали с исходниками. Проверены две независимые HttpOnly-cookie, отсутствие постоянного секрета в JSON и выборочный отзыв. После одного реального USB-reset оставшаяся cookie открыла API без owner key. Все проверочные допуски отозваны; пользовательские допуски не удалялись.

## Границы

На реальном Hub дневник читался без добавления фиктивных записей. Запись/повторная загрузка дневника и агрегация измерений проверены host-сценарием. Реальных графиков при отключённых датчиках нет. Принудительный аппаратный rollback, длительная работа/ресурс flash, несколько физических C3, реальные нагрузки, все браузеры/PWA и фоновые уведомления не проверялись. Установка проверена при текущем LAN-адресе; AP/другой адрес имеет отдельную cookie.

Напоминания видны в открытом приложении. Backup профилей не переносит дневник/историю/доступы; дневник экспортируется отдельным JSON, импорт пока не реализован. Неподтверждённые результаты не выдаются за успешные и не повторяются автоматически.
