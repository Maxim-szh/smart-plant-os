# Домашний UX 0.5 — 2026-11-05

## Что изменено

[Визуальная система и сверка](../UX-HOME.md), [контракт](../../spec/experience/v1/README.md), [ADR-0023](../adr/0023-home-rooms-journal-and-service.md). Комнаты стали группами с фильтром/сворачиванием/переносом. Дневник вынесен в навигацию, главную и карточки. Быстрые действия создают подтверждаемые записи, а не команды насосу. Добавление нескольких C3 использует краткую карточку и «Добавить ещё» после online.

Обслуживание сохраняет намерение Hub и отключает automatic через CONFIG с CAS Node; finish оставляет manual. Включение automatic через другой редактор блокируется, пока отметка обслуживания не снята. Источник истины — подтверждение и актуальное состояние C3, не открытый браузер.

## Программные проверки

- `npm run check`: контракты, документы, JS, локальные шрифты и запрет противоречивых состояний обслуживания.
- Native: 18/18. Новые случаи в API-тесте: старая ревизия, отказ записи Hub до радио, подтверждённый manual, неизменность калибровок, отсутствие авто-включения при finish, запрет включения automatic другим клиентом, offline и ошибка хранилища. Общий дневник возвращает существующие записи без записи flash и не принимает POST.
- Реальные C API-ответы: 5 прежних fixtures соответствуют публичным схемам. Новый контракт обслуживания дополнительно проверен примерами и native-проверками состояний.
- ESP-IDF v5.3.4: Hub S3 N8R2, Hub S3 N16R8 и Node C3 собираются. Образ Hub N8R2: 1 570 976 байт, помещается в OTA-слот 2 МиБ. Четыре файла woff2 занимают 183 336 байт; лицензии OFL включены.
- Новый `tests/web-home.cjs`: группировка/сворачивание/фильтр/перенос, быстрый дневник без actuator-команд, обслуживание start/finish/неизвестный исход/offline, две C3 подряд, защита черновика краткой карточки, setup_stage=1 без объявления готового оборудования, телефон и тёмная тема.
- Существующие браузерные сценарии привязки (`web-pairing`), безопасного редактирования (`web-care`) и системных служб (`web-system`) проходят.

## Визуальная проверка

IAB использован первым: проверены комнаты, перенос, ручная запись, обслуживание и два новых устройства за один сеанс. Viewport: 1488×1056 и 390×844. Для финальных снимков использован Playwright Chromium: один снимок IAB после смены размера имел неверный масштаб. Макеты Image Gen и финальные desktop/diary/service снимки просмотрены через view_image; палитра, типографика, отступы, иконки, навигация, переносы и отсутствие overflow сверены. Ledger и намеренные отличия — в [UX-HOME.md](../UX-HOME.md).

Визуальный стенд изолирован в tests/helpers/home-server.cjs. Его растения/записи/радиосостояния не входят в web или прошивку. Оригинальные SVG и скриншот README не менялись. Пример остаётся отдельным и доступен через настройки; дублирующая верхняя ссылка убрана.

## Реальный S3 N8R2

Перед обновлением проверен закреплённый отпечаток сертификата и сохранён приватный снимок каталога. Пакет 0.5.0-abi1 записан штатным USB update в неактивный OTA-слот; NVS не стиралась. После перезапуска:

- подтверждён запуск новой версии и завершение проверки загрузки;
- каталог в точности совпал со снимком перед обновлением;
- домашний HTTPS по прежнему адресу доступен;
- общий дневник и care-service доступны для чтения;
- 15 файлов с S3 совпадают SHA-256 с текущими исходниками: index/style/app/api/home/garden/plants/views/pairing/care и faces.css + 4 woff2;
- временный тестовый сеанс завершён, пользовательские доверенные браузеры не отзывались.

C3 физически не прошивалась. На реальную C3 не отправлялись CONFIG обслуживания или actuator-команды. Проверка управления manual выполнена native-симуляцией Node и mock-браузером, а не насосом. Физические датчики/полив и длительные проверки ресурса остаются отдельным стендом. Автоматическое возобновление после обслуживания и синхронизация browser-предпочтений комнат между устройствами не реализованы и не обещаются.
