# Первый запуск после сброса — 2026-11-02

Стенд: S3 N8R2 и C3 Super Mini, только USB, без исполнительных устройств.

## Выполнено

- Сохранено приложение предыдущей версии для USB-восстановления; старый NVS не используется для отката.
- На обеих платах USB-мастер проверил чип/разметку и выполнил явный factory-reset области NVS. esptool подтвердил стирание.
- S3 установлен как новый Hub с нулём растений. Новый admin key и сертификат отличаются от прежних; пароль AP — `smartplantos`. Запись приложения и NVS подтверждена hash-проверкой esptool.
- C3 подготовлен по публичному паспорту нового Hub; создан новый индивидуальный файл привязки, GPIO отключены. Старые ключи не восстанавливались.
- Native-проверки 5/5: ядро/протокол, политика AP, API, setup, AEAD/replay. Модель AP проверяет границы 30 s/60 s и кратковременное исчезновение сети.
- Python-проверки 5/5 для USB-мастера и 5/5 для provisioning. Проверены отмена reset и стирание только NVS на модели flash.
- Браузерные сценарии под CSP и проверки контрактов проходят. N8R2, N16R8 и C3 собираются.

## Последовательный мастер

- Добавлены отдельные экраны входа, Wi-Fi и готовности. Браузерные проверки подтверждают скрытие перехода до соединения, отсутствие раздела C3 на адресе AP, сохранение формы смены Wi-Fi при polling, мобильную и настольную ширину без горизонтального переполнения.
- В основной HTML восстановлен viewport; демонстрационный дизайн растений сохранён.
- S3 обновлён app-only через USB-мастер; hash проверен, NVS не записывался. Сборки N8R2, N16R8 и C3, native 5/5 и проверки контрактов проходят.
- Серверное перенаправление по локальному TCP-адресу собрано для S3; аппаратная проверка HTTP с телефона ещё ожидается. Проверка консоли без сброса не получила ожидаемую строку help и не считается доказательством запуска.
