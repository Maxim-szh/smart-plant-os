# Стенд 5 ноября 2026: профиль грунта 0.6

## Оборудование и границы

ESP32-C3 Super Mini, Capacitive Soil Moisture Sensor v1.2 на подтверждённом GPIO3, питание 3V3; ESP32-S3 N8R2 Hub в домашней сети. Исполнительных нагрузок нет, что подтвердил владелец. S3 N16R8 только собран, физически не проверен. Во время финальной проверки состояние/тип текущего образца не классифицировались: это проверка транспорта и ADC, не новая калибровочная точка.

## Проверено

- 19 native C сценариев, включая 30 с подтверждения сухости, скачок/восстановление, изменение частоты, длительное отсутствие отклика, подтверждение только разными измерениями и сохранение блокировки при reboot. Полив моделировался, реального насоса нет.
- npm run check, USB update/provision tests, браузерный сценарий отказа без обслуживания и минутной калибровки после active, CAS-конфликт и сохранение черновика. Часы/измерения в браузерном тесте моделировались.
- На исходных 19 CSV критерии окна приняли 17 стабильных записей и отклонили подтверждённый плохой контакт C и переход воздуха/воды B. Это та же серия, по которой настраивались параметры, не независимая проверка качества.
- Сборки ESP-IDF 5.3.4: C3, S3 N8R2, S3 N16R8.
- S3 обновлён через HTTPS OTA с проверкой сертификата. Подтверждены VALID, SHA-256 точного образа и побайтовое совпадение app.js/care.js/views.js с исходниками.
- C3 переведён из отдельного лабораторного образа обратно в обычную Node. Через USB явно записан только soil_pin=3. API подтверждает soil_configured=true, pump=false, tank_sensor=false. Калибровка не назначалась автоматически.
- После восстановления лабораторного backup прежняя связь штатно отвязана и заново согласована с новыми ключами. Проверены прежний plant ID, имя, комната, вид, стадия роста и полное совпадение управляющей конфигурации. Safety/бюджеты не сбрасывались. Первый обмен остаётся first_use_unverified, не PoP-аутентификацией.
- Без открытого USB-монитора получены четыре новых измерения через Hub за 30 с: ADC 3030/3022/3024/3022, возраст 970/2020/3081/1120 мс. Монотонные отметки образцов продвигались; качество uncalibrated, публичный soil_index_pct=null. Устройство online.

## Найденные ограничения установки

Открытие USB-порта на этом Mac может перезапускать C3. Первый ответ до прогрева ADC — missing, его нельзя принимать за постоянный отказ. Сброс во время OTA pending_verify вызывает штатный откат; одинаковый номер версии не подтверждает точный образ. Диагностические подключения не делаются в первые 30–90 с проверки загрузки.

Неблокирующий stdin базового USB VFS без RX-драйвера не принимал команды. Установлен ограниченный RX-драйвер, ввод читается напрямую с timeout=0, максимум 64 байта за цикл. Для stdout оставлен ограниченный базовый TX, без зависимости от чтения консоли компьютером.

Полный lab-образ использовал другую разметку; возврат старого NVS мог откатить радио-счётчики. Это не штатная процедура обновления. На стенде старые ключи выведены из использования новой привязкой. Для пользователей lab предназначен только для отдельной чистой платы; обычная OS обновляется без NVS.

## Что осталось проверить

Пользовательская калибровка в грунте после обновления, независимые переустановки, +10/+35 г, циклы высыхания, температура/удобрения/зазоры, длительная работа без компьютера и реальные насос/бак/питание.
