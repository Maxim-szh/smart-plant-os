# Проверка редакторов ухода — 2026-11-05

Это программный стенд с mock API, не испытание датчиков или полива. Физические S3/C3 в этой работе не перепрошивались. README и его скриншот не менялись.

## Проверено

- `npm run check`: синтаксис, существующие JSON-контракты/документы, новая проверка диапазонов и связанных параметров в `tests/care-checks.cjs`.
- Native: 18/18 существующих проверок; формат NVS, SPP и защитная логика Node не менялись.
- ESP-IDF v5.3.4: Hub S3 N8R2, Hub S3 N16R8 и Node C3 собираются. Новый ресурс care.js встроен в Hub и имеет HTTP-маршрут; Node его не включает.
- `tests/web-care.cjs`: противоречивые лимиты блокируют запись; предпросмотр показывает изменения; закрытие/Escape/уход со страницы защищают черновик; refresh не перерисовывает редактор.
- Два открытых клиента: первый редактор сохраняет, второй получает 409, сохраняет свои поля в форме и не перезаписывает актуальную конфигурацию. После явной загрузки актуальных данных запись снова доступна.
- Потеря HTTP-ответа и 503 `request_outcome_unknown`: повторное сохранение блокируется до чтения состояния. Фоновых повторов нет.
- Калибровка отправляет ревизию и неизменённые параметры из момента открытия, получает конфликт после чужого изменения. Успешная калибровка не вызывает ложного предупреждения при закрытии.
- Готовность: полный mock-профиль проходит проверки, offline не выдаёт положительных проверок. Эти чтения не отправляют команды или настройки. Разные номера прошивок при поддерживаемых возможностях не объявляются несовместимостью.
- Метаданные: конфликт оставляет имя/комнату и блокирует повторную запись устаревшего редактора. Дневник предупреждает при смене незавершённой формы.
- `tests/web-updates.cjs`: проверка профиля/SHA-256, передача частями, подтверждение запуска и продолжение после прерванной загрузки сохранились.
- `tests/web-pairing.cjs`: существующий путь поиска, профиля растения, калибровки и восстановления сеанса проходит с новым предупреждением.

Скриншоты не создавались. Проверка в браузере использует 390×844 и настоящие исходники HTML/CSS/JS под CSP.

## Ограничения

Купленные датчики ещё не исследованы; методика — [SOIL-TESTS.md](../SOIL-TESTS.md). Электрический монтаж, подача воды, стабильность ADC и ошибки контакта не подтверждены. Проверка готовности не выдаёт физическое разрешение полива. ABI C3 не передаётся отдельно и не объявляется проверенным по номеру версии. При принудительном завершении мобильного браузера предупреждение о черновике не гарантировано.
