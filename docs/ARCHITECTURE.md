# Архитектура (проект, не реализовано)

Документ описывает целевую архитектуру. Прошивки пока нет, часть решений требует проверки на железе.

## Три уровня
1. **Устройство (главное).** ESP32 хранит конфигурацию, историю и сам выполняет поливы. Работает без интернета.
2. **Домашний сервер (необязательно).** Для длинной истории, резервных копий и интеграций.
3. **Облако (необязательно).** Только как удобство, никогда как требование.

## Ядро устройства
- **Растение** — корневая сущность. К нему привязаны датчики, исполнительные механизмы и правила. «Зона полива» остаётся аппаратным каналом и скрыта от пользователя.
- **Actuator Gate.** Единственная дверь к насосу. Выдаёт временные «аренды» (lease): если приложение пропало, насос остановится по таймеру.
- **Safety Supervisor.** Независимый от интерфейса и ИИ слой с правом вето: суточный лимит воды, лимит за один полив, пустой бак, сухой ход, таймаут насоса.
- **Шина событий** внутри процесса с типизированными событиями.
- **Драйверы и манифесты возможностей.** Датчик описывает, что он умеет (`soil.moisture`, `air.temperature`, `light.lux`, `tank.level`).
- **Версионируемая конфигурация** с миграциями и ETag.

## Связь
- Локальный REST для конфигурации, WebSocket для событий (не SSE).
- MQTT и автообнаружение Home Assistant: пока не реализовано.
- Прошивка раздаёт интерфейс сама (LittleFS), отдельный сервер не нужен.

## ИИ (необязательно)
ИИ живёт вне устройства. Поток: **предложить → детерминированная проверка → подтверждение человеком → локальное выполнение.** ИИ никогда не открывает насос напрямую. Измеренное, расчётное и предложенное ИИ в интерфейсе визуально разделены.

## Железо (предварительно)
- ESP32-C3 4 МБ как референс для набора; ESP32-S3 рассматривается. Решение не принято.
- Ёмкостные датчики влажности почвы, SHT41 (воздух), BH1750 (свет), поплавок бака, реле или драйвер насоса.
- Стек: ESP-IDF, PlatformIO, LittleFS, `esp_http_server`.

## Известные риски
- Дрейф и коррозия дешёвых ёмкостных датчиков. Нужна калибровка и проверка правдоподобия значений.
- Влажность субстрата для коры (орхидеи) и торфа отличается, шкала «процентов» условна.
- Память C3 ограничена: история хранится прореженной (сырые 3 дня, по часам 30 дней, по суткам 365 дней).
