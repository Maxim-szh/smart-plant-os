# ADR-0001: Роли Smart Plant Hub и Smart Plant Node

Статус: Принято
Дата: 2026-10-24

## Контекст

Ранние документы описывали узел с собственным HTTP(S) API и «координатор» неопределённого размещения. Для C3 это означало TLS и HTTP-сервер в ограниченной памяти (документация Espressif называет около 40 КБ RAM на одно TLS-соединение, см. [SECURITY.md](../SECURITY.md)). Целевая система — распределённая: один ESP32-S3 и до десяти ESP32-C3.

## Решение

1. **Smart Plant Hub** (ESP32-S3 N16R8) обслуживает веб-интерфейс и единый REST API, ведёт реестр узлов и привязку, хранит настройки Hub и историю, предоставляет диагностику сети и будущие интеграции.
2. **Smart Plant Node** (ESP32-C3 Super Mini) обслуживает одно растение: почвенный датчик, датчик воды в баке, насос, калибровку, локальные правила и защиту. С Hub обменивается только по ESP-NOW.
3. **Hub определяет политику и координирует, Node проверяет и исполняет.** Hub предлагает конфигурацию и запросы; Node сверяет их с жёсткими пределами и текущим состоянием и сам решает, включать ли насос.
4. **Публичный REST API `/api/v1` принадлежит Hub.** Маршруты `/api/v1/nodes/{device_id}/…` из [PROTOCOL.md](../PROTOCOL.md) остаются единственной внешней поверхностью узла. Node не обязан иметь HTTP-сервер. Отладочный интерфейс узла возможен только как отдельное решение и не входит в MVP.
5. **Ни Hub, ни веб-интерфейс, ни ИИ, ни Home Assistant не имеют пути к GPIO насоса** в обход проверок Node.
6. Hub тоже имеет стабильный `device_id` вида `spo-…`. Схема описания Hub добавляется в этапе B как необязательное расширение v1.

## Последствия

- C3 освобождается от HTTP/TLS-стека, адрес для пользователя один.
- Hub становится единственной точкой доступа к управлению. Его отказ не включает насос и не отключает сохранённые правила Node, но лишает пользователя интерфейса и истории.
- Контракт `spec/v1` сохраняется: семантика `State`, `Config`, `CommandResult`, `EventPage`, `Registry` не меняется, изменяется только то, кто их отдаёт.

## Что не проверено

Бюджет памяти и числа задач Hub при одновременной работе Wi-Fi, HTTP-сервера и ESP-NOW не измерен. Бюджет памяти Node с ESP-NOW и без HTTP не измерен.
