# 0012 — Стендовый веб-доступ и реестр измерений
Статус: Принято
Дата: 2026-10-26

## Контекст

Нужен проверяемый путь от браузера к существующим защитам C3. Дизайн-прототип содержит функции следующих этапов и фиктивные значения; переносить их на устройство как работающие нельзя. Аналоговый драйвер почвы также не должен задавать архитектуру всех будущих датчиков.

## Решение

- Добавить `sp_sensors`: до восьми зарегистрированных драйверов, стабильный slot, тип, единица, период и срок годности. Драйвер возвращает fixed-point значение, качество и монотонное время. Типы: индекс почвы, наличие воды, температура, влажность воздуха, свет, напряжение, расход. Это контракт расширения, а не заявление о готовых драйверах всех перечисленных модулей.
- Профиль ADC вынести в `sp_soil_analog`; общая функция `sp_core_observe_soil` принимает нормализованный индекс. Назначение датчика источником защитной логики выполняется явно в адаптере платы. Добавление освещённости само по себе не меняет полив. NVS `state_v1` остаётся без изменения layout.
- `sp_api` преобразует публичные JSON-запросы в SPP и проверяет ответы. Обработчик HTTPS передаёт копии запросов через ограниченные очереди; доменными моделями и радио по-прежнему владеет application task. Истечение HTTP-ожидания не отменяет уже отправленную команду.
- Hub поднимает WPA2 AP на общем канале ESP-NOW и HTTPS на `192.168.4.1`. Сертификат и индивидуальные пароли генерируются при физической настройке; стандартных паролей нет. Проверка отпечатка — через комплект, полученный по USB-процедуре. HTTP без TLS не включается.
- Одна сессия на 15 минут, Bearer в оперативной памяти браузера; новый вход отменяет старую. Все API-чтения требуют авторизации. Вход ограничен пятью попытками в минуту. Cookie, CORS и сторонние ресурсы не используются. Изменения требуют JSON и проверенного Origin при его наличии; нативные клиенты используют тот же секрет. Защитные ограничения и частотный лимит мутаций остаются на C3; Stop их не ждёт.
- Рабочий интерфейс Hub находится в `web/index.html` и использует публичный API; `web/prototype.html` хранит визуальный концепт с демонстрационными сценариями и не подключён к железу. Наличие панели не означает, что все сценарии концепта реализованы.
- Имена и виды растений принадлежат Hub (`/plant`, отдельная revision). `Config` возвращает эти поля, но изменение поливной конфигурации не переименовывает растение. Это исключает ложную атомарность транзакции между Hub NVS и C3 NVS.
- Достоверные дополнительные измерения добавляются необязательным массивом `sensors` к State и Device capabilities. Старые поля сохраняются. Пока базовые capabilities соответствуют фиксированному профилю C3; динамический выбор оборудования и драйверов в браузере не реализован.
- Для неполного журнала прошивки добавить честный Event `device.event` с kind/status/reason/command ID. Не восстанавливать вымышленные `run_ms` или объёмы из одного события. Для Stop без UTC разрешить `finished_at: null` с явным `clock_state: unset`; завершённый Water по-прежнему требует времени.

## Последствия

Нет зависимости полива от браузера или HTTPS. Память под модель API и очереди выделяется на Hub, а не на каждый пакет C3. Сервер не обещает мгновенный Stop при занятых TLS-соединениях: независимое отключение насоса остаётся на C3. После неизвестного результата пользователь проверяет сохранённый ID, а не создаёт новый Water.

Восстановление старого NVS запрещено. Обновление действующей установки без веб-секретов сохраняет USB/радио, но не включает веб-доступ автоматически. Безопасное добавление/ротация веб-секретов без замены всего NVS ещё требует отдельного инструмента. Инструкция первоначального стенда — [FLASHING.md](../FLASHING.md).

## Что не проверено

Физическая работа AP + зашифрованный ESP-NOW, память и задержки при TLS-нагрузке, браузеры на телефонах с самоподписанным сертификатом, ресурс NVS и реальные датчики/насосы. Нужны аппаратный стенд и независимое ревью авторизации. Автопоиск оборудования, смена GPIO/драйверов через UI, NAS, microSD, Home Assistant, OTA и окончательная интеграция полного дизайна не реализованы.
