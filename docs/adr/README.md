# Архитектурные решения (ADR)

ADR фиксируют решения, которые влияют на несколько документов, схем или прошивок. Они короткие и не заменяют спецификации: ADR отвечает на вопрос «почему», а [архитектура](../ARCHITECTURE.md), [сеть](../NETWORK.md), [контракт](../PROTOCOL.md) и [правила полива](../WATERING.md) отвечают на вопрос «как».

Статусы: `Принято`, `Предложено`, `Заменено`, `Отклонено`. `Предложено` означает, что направление выбрано, но решение нельзя считать окончательным: в самом ADR перечислено, чего не хватает. Принятый ADR меняют новым ADR, а не правкой задним числом.

## Формат

Файл называется `NNNN-короткое-имя.md`. Обязательные строки сразу после заголовка: `Статус:` и `Дата:`. Разделы: «Контекст», «Решение», «Последствия», «Что не проверено». Раздел «Что не проверено» нельзя опускать: если проверок не было, так и пишем.
