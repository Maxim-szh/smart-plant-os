# ADR-0006: Автоматический канал Hub и ESP-NOW

Статус: Принято
Дата: 2026-10-30

## Контекст

У Hub один Wi-Fi радиоканал одновременно обслуживает домашнюю сеть, собственную точку доступа и ESP-NOW к C3. Роутер может выбрать канал автоматически и позже изменить его. Требовать от пользователя заходить в настройки роутера и фиксировать канал — плохой сценарий первого запуска.

ESP-IDF возвращает фактический канал подключённой станции через `esp_wifi_get_channel()`. В режиме AP+STA SoftAP автоматически переходит на канал роутера. ESP-NOW peer с `channel=0` использует текущий канал радиоинтерфейса. Документация: [Wi-Fi API ESP-IDF 5.3.4](https://docs.espressif.com/projects/esp-idf/en/v5.3.4/esp32/api-reference/network/esp_wifi.html), [ESP-NOW API](https://docs.espressif.com/projects/esp-idf/en/v5.4/esp32s3/api-reference/network/esp_now.html).

## Решение

1. Hub всегда поднимает собственную WPA2 точку доступа. Если заданы домашние Wi-Fi credentials и роутер использует поддерживаемый канал, Hub подключается как STA и автоматически определяет канал.
2. ESP-NOW использует текущий радиоканал Hub. Пользователю не нужно задавать канал роутера; `--channel` в мастере — только резерв для автономного режима.
3. C3 не подключается к домашней Wi-Fi сети. После пяти секунд без аутентифицированных сообщений он циклически ищет Hub на разрешённых каналах. Пока Node не найден, Hub отправляет ему поисковые `HELLO` чаще обычного. После валидного кадра Node фиксирует найденный канал до следующего тайм-аута.
4. При смене канала роутером Hub следует за STA, а C3 повторно ищет Hub. Локальная логика Node продолжает работать во время поиска.
5. Node в этом профиле ищет Hub на каналах 1–11. Если домашний роутер использует канал вне диапазона, Hub отключает STA и возвращается на резервный канал, чтобы сохранить автономную связь с C3.

## Последствия

- Первичная настройка не требует знания или ручной фиксации канала роутера.
- При смене канала управление от Hub может временно пропасть на время поиска C3; время восстановления требует измерений на физических платах.
- Домашняя сеть не является условием автономного полива. При её отсутствии работает точка доступа на резервном канале.
- Домашнее имя для TLS, настройка Wi-Fi из UI и Home Assistant остаются отдельными задачами.

## Что не проверено

Одновременная AP+STA+ESP-NOW работа, смена канала во время работы и цикл поиска C3 требуют проверки на S3/C3 с реальным роутером и помехами. Сборка прошивок не подтверждает поведение радио на стенде.
