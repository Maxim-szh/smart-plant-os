# Подключение Hub, C3 и браузера

Текущий поток: USB-установка → Wi-Fi SmartPlantOS → мастер HTTPS → домашняя сеть → основное приложение → поиск C3. Пошаговая инструкция: [SETUP.md](SETUP.md), прошивка: [FLASHING.md](FLASHING.md).

Телефон/ПК соединяется с ESP32-S3 Hub через его AP для настройки, затем через домашнюю сеть. ESP32-C3 не получает пароль роутера: связь с Hub идёт по ESP-NOW. Настройки и ограничения полива остаются на C3; отключение Hub или браузера не отменяет физическую автономность.

## Первый запуск

Подключитесь к SmartPlantOS (пароль smartplantos), откройте https://192.168.4.1. Корень AP ведёт в мастер, а не к растениям. Подтвердите владельца индивидуальным ключом, задайте домашний Wi-Fi. Мастер проверяет подключение до сохранения, показывает полученный адрес. Подключите телефон к домашней сети и откройте этот адрес: корень LAN открывает реальное приложение. Сохранение ключей при обновлении не зависит от браузерной сессии.

После устойчивого домашнего подключения AP выключается. Из приложения можно открыть восстановительную AP на пять минут. При ошибке новой Wi-Fi-конфигурации прежняя восстанавливается. Доступ к AP и LAN проверяется по локальному адресу принятого сокета, а не по подставленному Host. Браузерная cookie относится к конкретному адресу: первый вход на домашнем IP может потребовать ключ отдельно от AP.

## Каналы

Hub использует канал домашнего роутера автоматически. C3 ищет уже привязанный Hub при потере обмена. Текущий инженерный профиль ограничен каналами 1–11 и совместимым домашним WPA2 Personal/смешанным режимом; это не обещание поддержки любого регионального канала/роутера. При неподдерживаемом канале или недоступной домашней сети Hub возвращается к настройке и резервному каналу (обычно 6). Роутер может менять канал, поэтому ручное совпадение пользователем не считается нормальным рабочим сценарием.

Границы автоматического восстановления и работы при помехах проверяются отдельно на нескольких физических платах. Успешный callback отправки ESP-NOW не доказывает выполнение команды приложением.

## Постоянный вход

При входе отметьте «Запомнить этот браузер». Телефон и ПК имеют независимые допуски; список и отзыв доступны в «Настройки → Мои устройства». Перезагрузка S3 сохраняет доверенные допуски. Cookie не содержит owner key и недоступна JS. Другой адрес, инкогнито или очистка cookie могут потребовать новый вход. [Подробности](SECURITY.md).

C3 добавляются из главной страницы: «Добавить растение» → поиск рядом → выбор платы. Первый обмен без PoP — [ограниченный домашний профиль](adr/0015-first-use-radio-pairing.md). Наличие найденной платы само по себе не подтверждает её подлинность. Отвязка недоступной C3 на Hub не выключает её автономный полив; перед заменой физическое оборудование отключается.

Дневник, описание растения, напоминания и чтение накопленной истории доступны без включённой C3. Новые измерения требуют реального источника и времени на Hub. Приложение может один раз установить отсутствующее время по часам авторизованного браузера; часы с уже установленным временем не перезаписываются автоматически.
