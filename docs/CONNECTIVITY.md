# Подключение Hub, C3 и телефона

## Схема первой версии

```text
Телефон/компьютер ── Wi-Fi SmartPlantOS ──┐
Домашний роутер 2,4 ГГц ── Wi-Fi STA ────┼── ESP32-S3 Hub ── ESP-NOW ── ESP32-C3 Node(s)
                                         ┘
```

Hub создаёт собственную защищённую точку доступа для первоначальной настройки и веб-панели. Если при прошивке заданы домашний SSID и пароль, Hub одновременно подключается к домашней сети как Wi-Fi-клиент. C3 пока не подключаются к домашнему роутеру: они обмениваются данными с Hub по ESP-NOW и продолжают локально соблюдать ограничения полива при потере связи.

## Канал определяется автоматически

Роутер обычно сам выбирает канал, часто при запуске; некоторые модели могут сменить его позже. Заходить в настройки роутера и фиксировать канал не нужно.

Hub подключается к Wi-Fi 2,4 ГГц и считывает фактический канал через Wi-Fi-драйвер. У ESP32 один радиоканал, поэтому точка доступа `SmartPlantOS` автоматически переходит на канал домашнего роутера. ESP-IDF описывает это поведение для режима AP+STA в [руководстве Wi-Fi](https://docs.espressif.com/projects/esp-idf/en/v5.3.4/esp32/api-reference/network/esp_wifi.html).

C3 не подключается к роутеру. Если пять секунд не получает аутентифицированных сообщений Hub, он начинает перебирать разрешённые каналы. Hub чаще посылает поисковые `HELLO`, пока Node не вернулся в сеть. После подтверждённого сообщения C3 остаётся на найденном канале. Ожидаемый перерыв при смене канала — несколько секунд; точное время и устойчивость нужно проверить на стенде.

В текущем профиле ESP-IDF 5.3.4 C3 ищет Hub на каналах 1–11. Если роутер работает на канале вне этого диапазона, Hub отключит домашнюю сеть и вернётся к своей точке доступа на резервном канале, чтобы не оставить C3 без связи. Если домашний Wi-Fi не указан или временно недоступен, Hub и C3 также используют резервный канал `--channel` (по умолчанию 6).

Для изменения домашней сети сейчас потребуется новая установка через USB; менять SSID и пароль из веб-панели пока нельзя.

## Как открыть панель

Для первого входа подключите телефон к `SmartPlantOS` и откройте `https://192.168.4.1`. Пароль точки доступа и ключ администратора сохранены в созданном установщиком `access.json`. В поле панели вводите именно `admin_password`.

При заданном домашнем Wi-Fi Hub дополнительно получает адрес DHCP. Он печатается в USB serial monitor как `Home Wi-Fi connected ip=…`; тот же адрес виден в списке подключённых устройств роутера. В текущем прототипе TLS-сертификат выпущен для `192.168.4.1`, поэтому браузерный доступ через адрес DHCP может показывать предупреждение о несовпадении имени сертификата. Для панели используйте прямую точку доступа Hub. DHCP-адрес подтверждает подключение Hub в LAN, но сам по себе не означает готовую интеграцию Home Assistant.

## Ключи и файлы установки

`tools/install.py` автоматически:

- читает MAC-адреса плат по USB;
- создаёт отдельные случайные ключи для Hub и каждого C3;
- сохраняет общие ключи пар только в соответствующих NVS-образах;
- создаёт сертификат HTTPS и индивидуальный 32-символьный ключ администратора;
- записывает образы NVS непосредственно на платы.

Пользователь управляет одним ключом `admin_password` из локального `access.json`; радиоключи и CSV вручную редактировать не требуется. Каталог `secrets/` исключён из Git. Сохраните его в надёжном локальном месте, но не отправляйте вместе с баг-репортом и не добавляйте в репозиторий. Потерянный ключ администратора нельзя получить с платы; для восстановления потребуется отдельная процедура сброса, которая пока не реализована.

## Что пока не реализовано

- Изменение домашней сети, канала и пароля из веб-панели.
- Подключение C3 к Wi-Fi роутеру или самостоятельная смена канала ESP-NOW.
- Автоматическое обнаружение Hub в LAN и стабильное HTTPS-имя для доступа к панели через роутер.
- OTA обновление. Первое обновление и восстановление выполняются через USB.
- Завершённые испытания стабильности AP+STA+ESP-NOW при длительной работе и помехах.

Это ограничения текущего стендового профиля, а не обещание уже работающих функций.
