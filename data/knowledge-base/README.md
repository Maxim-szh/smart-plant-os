# База знаний о растениях

`plants.json` — стартовый справочник (54 вида) для подбора нормы полива, света и температуры.

**Статус: черновик.** Значения составлены по общим знаниям, не сверены с источниками и не проверялись экспертами. Это ориентиры, не диагноз. Перед тем как опираться на них в автоматическом уходе, каждую запись нужно проверить и указать источник.

## Поля записи
| Поле | Смысл |
|---|---|
| `id` | стабильный латинский идентификатор |
| `name_ru`, `latin` | название и латинское имя |
| `type` | `fruit`, `flower`, `leaf`, `succ` |
| `illustration` | какой силуэт рисовать в интерфейсе |
| `moisture_min/max` | норма относительной влажности земли, % (шкала откалиброванного датчика) |
| `drying_rate_pp_per_day` | типичная скорость высыхания, п.п. в сутки |
| `light_hours_min` | сколько часов яркого света в день |
| `temp_c` | комфортный диапазон, °C |
| `air_humidity_pct` | желательная влажность воздуха |
| `tip_ru` | короткий совет |

Стадия растения (росток, рост, цветение, плодоношение, покой) корректирует норму: см. `docs/KNOWLEDGE_BASE.md`.

## Как добавить растение
1. Добавьте запись в `plants.json`.
2. Укажите источник в описании PR.
3. Запустите `npm run check`.
