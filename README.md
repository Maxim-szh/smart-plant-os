# Smart Plant OS

Открытая локальная система ухода за комнатными растениями, томатами и перцами на подоконнике. Растение в центре, устройство на ESP32 работает без облака и подписок, интерфейс понятен без знания электроники.

> **Статус: ранний прототип.** Готов только интерфейс (кликабельный, на демонстрационных данных). Прошивка не написана, на реальном ESP32 ничего не проверялось. Не используйте для ухода за ценными растениями.

## Попробовать прототип
```bash
npm run serve        # http://localhost:8080/web/
```
или просто откройте `web/index.html`. Шрифты подгружаются с Google Fonts, без сети будут запасные.

В прототипе: коллекция растений, страница растения (сейчас, история, о растении), стадии ухода, свой алгоритм полива, события, настройки (основные и продвинутые), база растений, мастера добавления растения и датчика, состояния «нет связи / датчик не отвечает / бак пуст».

## Принципы
- **Локально.** Устройство главное, облако не обязательно.
- **Без подписок.** Никаких обязательных учётных записей и платных функций.
- **Безопасность детерминирована.** Лимиты воды и защиту насоса проверяет устройство, ИИ только предлагает.
- **Честные данные.** Измеренное, расчётное и совет ИИ показываются раздельно. Диагнозов система не ставит.
- **Открытость.** Код, документация и аппаратная часть под открытыми лицензиями.
