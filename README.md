# Smart Plant OS

Открытая локальная система ухода за растениями. Один узел на ESP32 обслуживает одно растение; несколько узлов объединяются в одном веб-приложении. Узел отвечает за измерения, решение о поливе и защиту насоса. Веб-приложение показывает состояние и отправляет команды, но не управляет насосом напрямую.

> **Статус: ранний прототип.** Работает только кликабельный интерфейс на демонстрационных данных. Прошивки, аппаратных испытаний и работающего API пока нет. Показанные GPIO, диагностические значения и интеграции не являются реализованными функциями. Не используйте прототип для полива растений.

![Главный экран](docs/img/home-desktop.png)

## Принятые решения

- Целевые платы: ESP32-S3 N16R8 и ESP32-C3 Super Mini. Точная распиновка зависит от ревизии платы и будет утверждена перед работой с железом.
- Один узел — одно растение, один почвенный датчик и один канал полива. Узел работает автономно при потере связи.
- Все узлы предоставляют один версионированный локальный контракт. В будущем локальный координатор собирает их в одном веб-приложении; Home Assistant обращается к тем же состояниям и командам через адаптер.
- Первый рабочий режим: ручной полив и автоматический полив по порогу влажности с ограничениями. Долгая история на microSD/NAS, сложные правила и ИИ запланированы на последующие этапы.
- База видов растений пока [черновая](data/knowledge-base/plants.json), без проверки по источникам. Её значения не должны автоматически становиться безопасными настройками устройства.

## Что показывает прототип
Коллекция растений с уникальным рисунком для каждого вида (растение «с характером»: размер зависит от стадии, поникает и просит воды, когда сухо), два режима ухода («Умный» полностью автономный по датчикам, стадии, сезону и статистике; «Вручную» с простым правилом или программой на псевдокоде), предложения сменить стадию, необязательный ИИ-помощник в настройках, рецепты ухода (применить, сохранить свой, поделиться файлом, импортировать), автоопределение стадии растения (по возрасту, расходу воды, свету и сезону), первый запуск (поиск платы по Wi‑Fi, датчики, комнаты, первое растение), напоминания «от вас» (долить воду, осмотр раз в неделю), страница растения (сейчас, история, о растении), стадии ухода, свой алгоритм полива, события, настройки (основные и продвинутые), база растений, мастера добавления растения и датчика, состояния «нет связи», «датчик не отвечает», «бак пуст», светлая и тёмная темы.

## Попробовать прототип
```bash
npm ci
npm run serve        # http://localhost:8080/web/
npm run check        # проверки базы, схем, примеров и скрипта
```
Или откройте `web/index.html` в браузере. Шрифты берутся с Google Fonts, без сети будут запасные.

## Участие

Перед изменениями прочитайте [CONTRIBUTING.md](CONTRIBUTING.md). Контрибьюторы особенно нужны для проверки справочника растений по источникам, работы с железом, доступности интерфейса и ревью контрактов.
