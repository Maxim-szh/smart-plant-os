# Smart Plant OS

Открытая операционная система для семейства ESP32, которая ухаживает за комнатными растениями, томатами и перцами на подоконнике. Растение в центре: вы видите не датчики и пины, а понятное состояние («в порядке», «нужна вода»). Всё работает локально, без облака и подписок.

> **Статус: ранний прототип.** Готов только интерфейс (кликабельный, на демонстрационных данных). Прошивки нет, на реальном ESP32 ничего не проверялось. Не используйте для ухода за ценными растениями.

![Главный экран](docs/img/home-desktop.png)

## Идея
- Устройство на ESP32 само читает датчики (влажность земли, свет, температура), решает, когда поливать, и управляет насосом. Интерфейс отдаётся прямо с устройства.
- Норма полива зависит от вида растения и стадии (росток, рост, цветение, плодоношение, покой). Для этого нужна база растений.
- Безопасность детерминирована: лимиты воды и защиту насоса проверяет устройство. ИИ (необязательный) может только советовать.
- Измеренное, расчётное и совет ИИ показываются раздельно. Диагнозов система не ставит.

## Этап проекта
| Часть | Состояние |
|---|---|
| Интерфейс ([`web/index.html`](web/index.html)) | прототип, работает в браузере, данные демонстрационные |

| Прошивка ESP32 | не начата |
| Локальный API, Home Assistant | не начаты |
| Аппаратная часть (плата, набор) | не начата |

## Что умеет прототип
Коллекция растений с уникальным рисунком для каждого вида, страница растения (сейчас, история, о растении), стадии ухода, свой алгоритм полива, события, настройки (основные и продвинутые), база растений, мастера добавления растения и датчика, состояния «нет связи», «датчик не отвечает», «бак пуст», светлая и тёмная темы.

## Попробовать
```bash
npm run serve        # http://localhost:8080/web/
npm run check        # проверка базы и скрипта
```
Или откройте `web/index.html` в браузере. Шрифты берутся с Google Fonts, без сети будут запасные.
