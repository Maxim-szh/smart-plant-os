Вход в систему

Откройте файл access.json, созданный мастером установки, и скопируйте значение admin_password. Ключ и сессия не сохраняются в браузере.

Инженерная версия. Автономные ограничения проверяет ESP32-C3. Нет данных — не означает нулевое значение. Аппаратные испытания ещё необходимы.
