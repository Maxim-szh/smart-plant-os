Точка SmartPlantOS · пароль smartplantos
Ключ администратора индивидуален для вашего устройства.

Введите ключ администратора или выберите файл доступа, сохранённый при установке.

Подтвердите, что это ваш сад

Ключ находится в вашем access.json. Для готового устройства его передаёт владелец или сборщик.

Загрузить ключ из файла

Обычное обновление сохраняет ключ. Полный сброс и повторная установка создают новый.

Подключим домашний Wi-Fi

Выберите сеть 2,4 ГГц. Сначала проверим подключение, затем сохраним его на ESP32.

Проверка занимает до 30 секунд. Если пароль не подойдёт, можно попробовать снова.

Ваш сад теперь в домашней сети

Подключите телефон или компьютер к той же домашней сети. Затем откройте приложение по этому адресу:

Открыть растения

Точка SmartPlantOS выключится после 30 секунд устойчивого подключения. Браузер не может сам переключить Wi-Fi телефона.

Ручная USB-привязка ранних устройств

Для нового C3 откройте приложение растений и нажмите «Добавить растение». Инструкции ниже нужны только для прежнего способа подготовки по USB.

Скачайте паспорт Hub и передайте его программе установки при подготовке нового ESP32-C3 по USB.

Затем выберите созданный программой приватный файл node-pairing.json.

    Файл содержит ключи конкретного C3. Не публикуйте его. Новые контроллеры подключаются через автоматический поиск в приложении.

    Обновление прошивки

    В программе для компьютера выберите «Обновить прошивку». Настройки сети и ключи сохранятся.

    После однократной USB-миграции можно обновлять Hub и C3 из приложения.
