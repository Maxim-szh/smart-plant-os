Шаг 2 · Растения

Добавить ESP32-C3

Скачайте паспорт Hub. Подключите новый C3 к компьютеру по USB и выберите «Подготовить новый C3» в программе установки. Передайте ей этот паспорт.

Программа сохранит приватный файл node-pairing.json. Загрузите его здесь, чтобы связать C3 с вашим Hub.

Файл привязки содержит индивидуальные ключи этого C3. Храните его как пароль. Автоматический поиск непривязанных устройств по радио пока не включён.

    Обновления

    Сохранить настройки при обновлении

    В программе для компьютера выберите «Обновить прошивку», подключите плату по USB и укажите пакет для вашей модели. Сохранённые ключи и настройки останутся на плате.

    Для этой разметки flash обновление через браузер ещё не доступно. Не запускайте первичную установку для обновления работающей системы.
