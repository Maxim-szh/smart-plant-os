# Работа над Smart Plant OS

Перед изменениями прочитайте [CONTRIBUTING.md](CONTRIBUTING.md), [план](docs/ROADMAP.md) и нужную спецификацию. Один узел обслуживает одно растение; полив и все защитные ограничения принадлежат узлу. `web/index.html` пока содержит только демонстрационные значения. Форматы будущего API определены в `spec/v1`; меняйте схему, пример и документацию вместе. Проверяйте изменения командой `npm ci && npm run check`. Точные GPIO не назначайте без проверки конкретной ревизии платы. В коммитах используйте `Signed-off-by`.
