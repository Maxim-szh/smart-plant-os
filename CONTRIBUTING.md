# Как участвовать

Спасибо, что хотите помочь. Проект ранний, правила простые.

## Прежде чем начать
- Для крупных изменений сначала откройте issue и обсудите идею.
- Не добавляйте обязательные облачные сервисы, аккаунты или телеметрию.
- Автоматический полив должен оставаться безопасным без интернета и без ИИ.

## Разработка
```bash
npm run check     # проверка JSON и синтаксиса скриптов прототипа
npm run serve     # локальный просмотр
```
Прототип лежит в одном файле `web/index.html`. Токены цветов, типографика и компоненты описаны в [`docs/DESIGN.md`](docs/DESIGN.md): сначала используйте существующие, потом добавляйте новые.

## Коммиты и PR
- Короткие осмысленные коммиты, в стиле `область: что сделано` (например, `web: график истории`).
- В PR опишите, что изменилось и как проверили. Для интерфейса приложите скриншот на телефоне и на широком экране, в светлой и тёмной теме.
- Для базы растений укажите источник.

## DCO
Мы используем Developer Certificate of Origin. Добавляйте подпись к коммиту: `git commit -s`. Так вы подтверждаете, что вправе передать код под лицензией проекта (https://developercertificate.org).

## Доступность
Статус не передаётся одним цветом: цвет, иконка и слово. Контраст текста не ниже WCAG AA. Анимации уважают `prefers-reduced-motion`.
