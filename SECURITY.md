# Безопасность

Проект ранний, прошивки пока нет. Когда она появится, устройство будет управлять насосом и сетью, поэтому уязвимости важны.

О проблеме безопасности сообщайте **приватно** (раздел Security → Report a vulnerability в репозитории), не в публичных issue.

Принципы: локальный API, без облака по умолчанию; аппаратные лимиты воды независимы от приложения; обновления прошивки подписываются (планируется).
