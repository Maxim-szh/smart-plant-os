# Минутные измерения почвы

Отдельная лабораторная прошивка `firmware/soil-bench`, **не обычная Node**. Только C3, ADC1 GPIO3, 12 бит, attenuation 12 dB. Нет Wi-Fi, полива, изменений NVS. Лабораторный образ предназначен только для отдельной чистой платы. Его стандартная разметка ESP-IDF несовместима с разметкой Node: `idf.py flash` поверх установленной OS может перезаписать часть NVS. Не используйте его как обновление действующей Node. На установленной Node используйте основной мастер калибровки. Не используйте с насосами и реле. Полные USB-образы могут содержать ключи. Возврат старого NVS может откатить radio epochs: после такого лабораторного восстановления нужна новая привязка с новыми ключами без сброса safety-лимитов. Штатные обновления OS выполняются через OTA без NVS.

Запуск страницы из корня репозитория:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory tools/soil-bench-web
```

Откройте http://localhost:8765 в Chrome или Edge на Windows/Linux/macOS. Safari/Firefox Web Serial не поддерживают. Нажмите «Подключить C3 по USB», выберите порт. Linux может потребовать доступ к последовательному порту. Закройте другие serial monitor.

Питание датчика: VCC → 3V3, GND → GND. Сначала измерьте мультиметром AOUT относительно GND. Рабочий измерительный диапазон ADC C3 при таком ослаблении примерно до 2,5 В, а не до 3,3 В. При превышении нужен согласованный делитель, иначе измерение насыщается. После проверки AOUT → GPIO3 (надпись «3», не «3V3»). Цвет проводов не заменяет маркировку. Меняйте датчик при отключённом USB. Не погружайте электронную часть в воду.

Выберите A/B/C, образец и фактическую массу, нажмите «Записать 60 секунд». CSV автоматически скачивается после завершения/прерывания; проверьте файл. Дополнительно скачайте JSON с исходными пакетами и причинами прерывания. До закрытия страницы все опыты доступны в списке. Постоянной базы в браузере нет, несохранённые данные пропадут при закрытии. При отключении USB текущая запись завершается как прерванная.

План: воздух → исходный грунт → чистая вода → грунт +23 г воды → грунт +50 г воды. Три отдельных образца по 60 г исходного грунта, тара 2 г. Ожидаемые полные массы 62/85/112 г **не подставляются вместо измеренных**. Исходный грунт не считается абсолютно сухим. Воду равномерно перемешать и дать распределиться; минутная запись не является временем подготовки грунта. Одинаковые глубина, уплотнение, вода и положение; между этапами аккуратно промокнуть чувствительную часть. Повторить для трёх датчиков; полезна контрольная запись воздуха в конце.

Формат USB: JSONL `kind=soil_bench`, `v=1`, `firmware=bench-1`, `gpio=3`, `seq`, `device_ms`, `raw` — 9 значений 0..4095 или null при ошибке ADC. Один пакет каждые 500 мс, девять быстрых чтений в пакете имеют общую временную метку. CSV содержит отдельную строку на каждое чтение. 0/4095 отмечаются rail, null — adc_error; это признаки для проверки, не автоматический диагноз датчика. Проценты влажности и милливольты не вычисляются. График/текущее число показывают медиану пакета, файлы сохраняют все чтения. Разрывы seq отмечаются в JSON; перезапуск/тайм-аут прерывает опыт. Неподключённый ADC плавает: эти значения не являются результатом датчика.

Сборка (в активированном ESP-IDF 5.3):

```sh
idf.py -C firmware/soil-bench set-target esp32c3
idf.py -C firmware/soil-bench build
idf.py -C firmware/soil-bench -p ВАШ_ПОРТ flash
```

Для запуска двойным щелчком есть `start.command` (macOS/Linux, установлен Python 3) и `start.cmd` (Windows, Python с launcher `py`). На Linux также можно запустить `sh start.command`. Сервер слушает только этот компьютер. При закрытии терминала страница перестанет загружаться.

Проверка кнопок без платы: `BENCH_BROWSER=/путь/к/chromium node tests/soil-bench-web.cjs` (или без BENCH_BROWSER, если установлен браузер Playwright). Этот тест использует искусственные данные только внутри изолированной страницы, не создаёт файлы реального опыта.
