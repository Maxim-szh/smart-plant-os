Проверяем датчики почвы

Один датчик, один образец, одна минута. Сохраняем исходные значения ADC без пересчёта в проценты влажности.

Откройте эту страницу в Chrome или Edge на компьютере.

Подключение: VCC → 3V3, GND → GND, AOUT → GPIO3. Сначала проверьте выход мультиметром. Не мочите электронику датчика.
